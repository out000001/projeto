# Skills do projeto

Pacote Addy Osmani instalado em `.agents/skills`, com os checklists compartilhados em `.agents/references`. As skills ficam disponíveis para agentes que leem skills locais deste repositório. Não há instalação global na máquina do usuário.

Origem e versão: `installed-skills.json`. Licença: `ADDYOSMANI_LICENSE`. Scripts de origem não foram executados durante a instalação.
